
# Hangman Game

A simple command-line Hangman game built in Python.

## Description

This game randomly selects a word from a predefined list and asks the player to guess letters one at a time. The player wins if they correctly guess the word before using up all their allowed wrong attempts.

## Features

- Random word selection
- Hidden word display using underscores
- Letter validation
- Wrong guess tracking
- Replay option after each game
- Simple console-based gameplay

## Requirements

- Python 3.8 or later

## How to Run

1. Save the game code in a file named `hangman.py`
2. Open a terminal or command prompt
3. Run:

```bash
python hangman.py
